# AURENIX — Contexto de Negocio

> AURENIX no es una agencia de marketing. Es una empresa de crecimiento digital que construye **sistemas de adquisición** para negocios. Su producto central es el **D.A.S. — Digital Acquisition System**.

## 1. Qué es AURENIX

AURENIX toma negocios que dependen de métodos tradicionales de venta (referidos, WhatsApp, tráfico físico, publicaciones orgánicas) y los convierte en sistemas capaces de:

**Digitalizar → Adquirir → Convertir → Optimizar → Escalar → Automatizar**

No vende una web, publicidad o contenido de forma aislada. Construye la infraestructura y el proceso para que un negocio adquiera clientes de forma sistemática.

## 2. Problema que resuelve

**Problema central:** ventas sin sistema de adquisición. Un negocio puede tener buen producto, buen precio y clientes satisfechos, y aun así depender de que alguien lo conozca, lo recuerde, le escriba y compre.

Problemas derivados: presencia digital débil, canales desconectados, publicidad sin hipótesis, ausencia de datos, decisiones por intuición, imposibilidad de saber qué funciona, dificultad para escalar.

## 3. Cliente ideal

- **Quién:** dueño, fundador o responsable de crecimiento de un negocio tradicional o pyme (comercio, servicios, retail, ecommerce, negocio local con potencial de expansión). Edad aprox. 28–55.
- **Ya tiene:** producto/servicio validado, capacidad operativa, base comercial, probablemente usa WhatsApp como canal de venta.
- **Le falta:** un sistema digital de adquisición predecible.
- **No busca:** aprender marketing. Busca resolver "¿de dónde van a salir mis próximos clientes?".

**Problema funcional:** Negocio → publicaciones → esperar → mensajes ocasionales → ventas (depende de casualidad o recomendación).

**Problema emocional:** incertidumbre → dependencia → frustración → sensación de estar atrasado → falta de control.

**Lo que quiere sentir al trabajar con AURENIX:** no "qué agencia tan creativa", sino *"finalmente entiendo cómo funciona mi adquisición"* y *"tengo control"*. Los cuatro deseos emocionales clave son: **Control, Claridad, Seguridad, Progreso** (y a nivel de negocio, **Escalabilidad**).

## 5. El D.A.S. — Digital Acquisition System

Sistema de **diagnóstico y evolución**, no una lista rígida de servicios: *Diagnosticar → Identificar cuello de botella → Intervenir → Medir → Aprender → Decidir siguiente movimiento*. No siempre empieza en "Digitalizar"; un negocio puede entrar directo en cualquier fase según su diagnóstico.

| Fase | Pregunta que responde | En una palabra |
|---|---|---|
| 01 Digitalizar | ¿Tenemos la infraestructura necesaria? | Infraestructura |
| 02 Adquirir | ¿Podemos generar oportunidades? | Tráfico |
| 03 Convertir | ¿Podemos convertirlas en clientes? | Ventas |
| 04 Optimizar | ¿Sabemos qué funciona y qué mejorar? | Datos |
| 05 Escalar | ¿Podemos crecer sin romper el sistema? | Crecimiento |
| 06 Automatizar | ¿Podemos reducir intervención manual? | Eficiencia |

**Regla de movimiento (lógica de decisión):**
- Sin infraestructura → Digitalizar
- Con infraestructura pero sin oportunidades → Adquirir
- Con oportunidades pero sin ventas → Convertir
- Con ventas pero sin saber qué funciona → Optimizar
- Sabiendo qué funciona y queriendo más → Escalar
- Sistema funcionando pero consume mucho trabajo manual → Automatizar

Es un **ciclo, no una escalera**: se puede volver de Escalar a Optimizar, o de Optimizar a Adquirir, etc.

### La unidad básica de trabajo: el Experimento

Toda intervención relevante se documenta como: **Hipótesis → Pregunta → Variable → Control → Ejecución → Datos → Aprendizaje → Decisión**.

### Protocolo universal de AURENIX (aplica a cualquier intervención)

01. Contexto — ¿qué está pasando?
02. Problema — ¿qué impide avanzar?
03. Hipótesis — ¿qué creemos que lo causa?
04. Experimento — ¿qué haremos para comprobarlo?
05. Ejecución
06. Datos
07. Aprendizaje
08. Decisión

### D.A.S. Operating File (por cliente)

Cada cliente tiene un archivo con: Contexto, Diagnóstico, Objetivo, Cuello de botella, Hipótesis, Experimentos, Datos, Aprendizajes, Decisiones, Implementaciones, Próximo movimiento. AURENIX no solo presta un servicio: **construye memoria operacional del negocio**.

## 6. Propuesta de valor

- **Principal:** "Construimos sistemas para conseguir clientes."
- **Comercial:** "Convertimos negocios tradicionales en sistemas digitales capaces de adquirir clientes."
- **Completa:** AURENIX construye sistemas de adquisición digital para que los negocios consigan clientes de forma medible, optimizable y escalable.

**No promete:** duplicar ventas, hacer millonario a nadie, garantizar resultados ni viralizar. **Sí promete:** construir el sistema, medirlo y optimizarlo continuamente.

## 7. Posicionamiento

AURENIX **no** se posiciona como agencia de marketing digital, agencia de Meta Ads ni agencia de diseño web (eso la reduce a proveedor y la mete a competir con miles). Se posiciona como una **empresa especializada en sistemas de adquisición digital**, en el territorio: *Digital Growth + Acquisition + Systems*.

Frases clave de diferenciación:
- "No es publicidad. Es adquisición."
- "No es una tienda. Es un sistema para vender."
- "No optimizamos campañas. Optimizamos sistemas."

## 10. Jerarquía de mensajes

- **Mensaje principal:** Construimos sistemas para conseguir clientes.
- **Explicación:** AURENIX ayuda a los negocios a construir, activar y escalar su adquisición digital conectando infraestructura, publicidad, conversión, datos y automatización.
- **Problema:** Conseguir nuevos clientes no debería depender solo de recomendaciones o publicaciones.
- **Solución:** Un sistema que atrae, convierte, mide y optimiza.
- **Diferenciador:** No ejecutamos marketing por ejecutar; cada acción responde una pregunta.

## 11. Filosofía interna

**Hipótesis → Ejecución → Datos → Aprendizaje → Optimización.**

AURENIX no solo aplica el D.A.S. a sus clientes: también experimenta sobre sí misma (adquisición propia, ofertas, canales) usando la misma lógica. Los casos reales (ej. Zeus Pet Shop) sirven como laboratorio para mejorar el propio sistema.
