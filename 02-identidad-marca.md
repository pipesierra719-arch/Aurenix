# AURENIX — Identidad de Marca

> Dirección: **empresa tecnológica + consultoría estratégica + sistema operativo de crecimiento.** Estética: minimalista, tecnológica, precisa, premium, modular, sistémica.

## 1. Nombre y descriptor

```
AURENIX
D.A.S. — Digital Acquisition System
```

En mayúsculas en aplicaciones institucionales. El descriptor D.A.S. siempre acompaña al nombre para explicar qué hay detrás de la marca.

## 2. Emociones que debe transmitir

1. **Confianza** — es una empresa seria.
2. **Control** — estructura y dominio.
3. **Inteligencia** — trabaja con hipótesis, datos, experimentación.
4. **Progreso** — sensación de movimiento, sin caer en cliché de marketing.

**Deliberadamente evita:** diversión, energía excesiva, colores juveniles, estética "gurú digital", estética startup genérica, agresividad comercial.

## 3. Paleta de color oficial

Decisión clave: **Dark Tech + Electric Gold** — no el típico negro + azul eléctrico (demasiado común en SaaS/IA), y explícitamente **sin morados/violetas** (`#7C3AED`, `#8B5CF6`, `#6366F1` quedan fuera: comunican "otra empresa de IA/SaaS genérica").

| Rol | Nombre | HEX | Uso |
|---|---|---|---|
| Color base | Obsidian | `#0B0D10` | Fondo principal — autoridad, precisión, tecnología |
| Fondo secundario | Graphite | `#15191F` | Separar módulos, cards, bloques |
| Acento 1 (marca) | Aure Gold | `#C9A227` | CTAs, indicadores, números importantes, hover — **con moderación, nunca para pintar toda la página** |
| Acento 2 | Titanium | `#8E98A7` | Info secundaria, iconos, labels, líneas, gráficos |
| Texto principal | Ice White | `#F2F4F7` | Texto sobre fondo oscuro (no usar blanco puro `#FFFFFF`, resulta agresivo) |

### Lógica simbólica de la paleta

```
OBSIDIAN  → estructura / sistema / autoridad
ICE WHITE → claridad / información
TITANIUM  → datos / tecnología / interfaz
AURE GOLD → acción / valor / progreso
```

Mapea directamente al D.A.S.: *Infraestructura → Tráfico → Ventas → Datos → Crecimiento → Eficiencia*.

## 4. Tipografía (del prototipo actual)

- **Títulos / display:** `Space Grotesk` (peso 600), `letter-spacing: -0.01em`
- **Cuerpo de texto:** `Manrope` (400–700)
- Tamaño base: `16px`, `line-height: 1.6`

## 5. Qué evitar visualmente

❌ Personas sonriendo · ❌ megáfonos · ❌ cohetes · ❌ gráficos de crecimiento genéricos · ❌ bombillos · ❌ exceso de colores · ❌ estética "marketing guru" · ❌ landing convencional tipo Hero → beneficios → testimonios → precios → CTA sin más (AURENIX pide algo más sistémico, ej. mostrar visualmente las 6 fases conectadas).

## 6. Tono verbal

Directo, sin humo. Ejemplos de frases marca:

- "Construimos sistemas para conseguir clientes."
- "No es publicidad. Es adquisición."
- "No es una tienda. Es un sistema para vender."
- "No optimizamos campañas. Optimizamos sistemas."

La identidad debe funcionar igual en: una propuesta comercial, una presentación, una web, un dashboard, una campaña, un documento estratégico o una interfaz de software.

## 7. Checklist rápido antes de diseñar o escribir algo para AURENIX

- [ ] ¿El fondo es Obsidian/Graphite, no blanco?
- [ ] ¿El dorado se usa con moderación (CTA, números clave, hover), no como color dominante?
- [ ] ¿El copy suena a sistema/proceso, no a "agencia creativa" ni "gurú de marketing"?
- [ ] ¿Se evita el morado/azul-violeta típico de SaaS/IA?
- [ ] ¿La pieza transmite control y claridad, no solo estética bonita?
